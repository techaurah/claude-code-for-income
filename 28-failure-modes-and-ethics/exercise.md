# Exercise for Lesson 28: Failure modes and ethics: staying in business

Describe your next real project in the project JSON shape and run the pre-mortem generator. Complete every owner and control field in the register it produces, in writing, before any work starts. Then write the disclosure sentence for your proposal, the opt-out line you would refuse to automate around, and the dependency check you will run at delivery. If any control field is still blank because the honest answer is uncomfortable, that field is the exercise: resolve it now, on paper, rather than mid-project, in a call.
