# Capstone showcase

Finished capstone engagements from learners of Claude Code for
Income. This table is the course's completion artifact: no
certificates, just delivery packs anyone can open and inspect.

## How to get your capstone indexed

1. Finish the capstone (Lessons 29 to 31). Your delivery pack must
   be in a public repository of your own, with the brief, the
   priced scope with its assumptions, the QA gate record, and the
   handover pack. Remove anything that identifies a real client;
   the capstone client is fictional and yours should stay that
   way too.
2. Fork this repository and add **one row** to the table below:
   your name or GitHub handle, a link to your capstone repository,
   and one line describing the engagement and its proudest honest
   limit.
3. Open a pull request titled `Showcase: <your handle>`. Small,
   single-purpose PRs like this merge directly under the course's
   [two-tier contribution rule](../CONTRIBUTING.md); you do not need
   to open an issue first.
4. A maintainer checks that the link works and the pack is
   complete (or that the README honestly says what state it is
   in). Working beats polished.

One row per learner. If you redo your capstone later, update your
row with a second PR.
