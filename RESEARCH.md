# Competitor research: an advanced Claude Code course about earning income

Written 2026-11-07, before any lesson was drafted, per the TechAurah
GitHub programme rule: competitor research first, always. Every fact
below was observed in web search results or pages fetched on that
date. Star counts, learner counts and prices are point-in-time
observations from the named source, not live guarantees, and where
a claim could not be verified or rests on a single self-interested
source, that is recorded rather than smoothed over. This document
also carries the publish decision the programme owner delegated:
is this course worth building at all?

## The question

Tech ordered an advanced course (his words: a level course, not
beginner, not intermediate) on using Claude Code as an income
source: side income and serious client work, complete, with proper
visuals, nothing missed. The decision rule he set: research first,
publish only if it is worth it, and honest framing is a hard
condition. No income guarantees, no fabricated earnings, real cost
math. This research tests the idea against three questions:

1. Is there real demand beyond hype?
2. Does a dominant free, complete, advanced course already own
   this exact angle?
3. Can it be taught honestly, with real workflows and real cost
   math?

## What already exists: courses about Claude Code the tool

### The official path (free, short, tool-focused)

- **Anthropic Academy, Claude Code in Action.** Free, about 3
  hours, Anthropic's own curriculum (also on Coursera and
  DataCamp). Covers first prompts, daily workflows, customisation,
  CLAUDE.md, MCP. DataCamp's course index (ratings and learner
  counts verified there 2026-09-24) lists it at 3,221 learners and
  labels it the advanced follow-on: steering long sessions, hooks,
  scheduled prompts (routines), handing jobs off through GitHub,
  verifying what comes back. That is the strongest free advanced
  material in existence, and it is three hours about operating the
  tool. It says nothing about clients, pricing, or delivery as a
  paid service.
- **Anthropic via DataCamp, Claude Code 101.** Free, 3 hours,
  27,000 learners on DataCamp's index, rated 4.8/5. Beginner to
  intermediate: installation, prompting, context management,
  CLAUDE.md, subagents, MCP, hooks. The 27K learner count is the
  single clearest demand datapoint for Claude Code training: a
  beginner course on one platform drew twenty-seven thousand
  people.
- **DeepLearning.AI, Claude Code: A Highly Agentic Coding
  Assistant.** Free, 1 hour 50 minutes, MCP-focused short course.
- **Lydia Hallie, Claude Code (Masters.dev).** Free; taught by a
  member of the Claude Code team. Tool craft from the inside.
- **Vanderbilt on Coursera, Software Engineering with Generative
  AI Agents.** Free to audit, 5 hours, rated 4.7/5. Academic frame,
  agents generally, not Claude Code income work.

### The paid shelf (deeper, still tool-only)

- **Code with Mosh, Claude Code for Professional Developers.**
  $249, 9 hours, 120 lessons, intermediate. Builds one production
  full-stack app; strong on reviewing AI output. One project, one
  stack, no business content.
- **AI Hero, Claude Code for Real Engineers.** $795, two-week live
  cohort, six office hours. The most advanced paid offer found:
  PRDs, tracer bullets, multi-phase planning, autonomous loops,
  GitHub Issues integration, aimed at senior engineers. Advanced
  tool craft at a premium price, sold to employed engineers, not
  to people building an income practice.
- **Frank Kane, Claude Code: Building Faster with AI (Udemy).**
  About $15 at typical sale pricing, 5 hours. Prototype to
  production with one project.
- **The Udemy long tail.** Roundups (one reviewer worked through
  20 to 30+ courses) converge on the same shape: practical guides,
  masterclasses about coding speed, beginner-to-pro paths. All of
  them teach a person to operate Claude Code on their own work.

### GitHub as a classroom (directories and showcases, not courses)

- **hesreallyhim/awesome-claude-code.** About 56,000 stars
  (GitHub API star count checked 2026-10-21 by a third-party
  guide; a hands-on test on 2026-11-05 saw 57,300). The ecosystem's
  curated directory: 263 catalogued resources across skills,
  hooks, slash commands, orchestrators, status lines, and more.
  A directory is a map, not a curriculum; it teaches discovery,
  not judgement, and nothing about earning.
- **travisvn/awesome-claude-skills.** About 12,000 stars. Skills
  only, same directory shape.
- **diet103/claude-code-infrastructure-showcase.** About 10,000
  stars. One practitioner's real setup (skill auto-activation,
  hooks, agents) published as an example. Excellent raw material,
  no teaching arc.
- **disler/claude-code-hooks-mastery.** About 3,900 stars. Deep on
  one feature.
- Anthropic's own skills and plugin repositories round out the
  shelf: parts and patterns, distributed free, with no course
  wrapped around them and no income curriculum anywhere.

Reading of the shelf: the tool is superbly documented and the
advanced tool craft exists, free in fragments and paid in cohorts.
What does not exist in course form, at any price found, is the
business system: how a practitioner turns these workflows into
scoped, priced, quality-gated, repeatable paid work.

## What already exists: "make money with Claude Code" content

The income angle is owned today by blogs, Medium posts, and
YouTube, and the genre's standards are low:

- **Medium and listicle guides** (examples read: a "personal AI
  programmer" system promising $5K to $10K a month; a "5 real
  business models" listicle) publish rate cards with no source
  ($800 to $2,500 per chatbot build, $500 to $2,000 per setup) and
  anecdotes with no evidence ("one freelancer earned $12,000 in
  three months", attributed to nobody). The arithmetic is
  presented as typical; nothing is labelled an assumption.
- **One first-person case with claimed receipts:** a marketer
  packaged about 20 Claude skills into a $99 digital product and
  reports over $5,000 in about 50 days, over $20,000 by September
  2026, plus one $1,000 consulting upsell from a buyer. Self
  reported on his own site, selling the same product the post
  describes. Worth citing as an existence proof that skills
  packaging sells, worthless as a typical outcome.
- **The careful end of the genre** (a personal-finance guide to
  making money with Claude) does cite platform data and plan
  prices and runs a break-even calculation, which proves the
  honest version is possible; it is one article, beginner level,
  and stops where the advanced material starts.
- YouTube's Claude Code income videos follow the same pattern as
  the blogs: big-number titles, workflow demos, no cost ledger.

Gap, stated plainly: the people searching this angle are being
served hype. A complete, advanced, free course that pairs the real
power workflows with scoping, pricing, QA, packaging, and a cost
ledger, and labels every worked example as a worked example, has
no incumbent.

## Demand evidence

Hype is not demand, so each signal below is a platform's own
numbers or a counted audience, with its limits stated.

- **Upwork In-Demand Skills 2026** (published February 2026;
  based on completed jobs with real freelancer earnings, January
  to December 2025, US marketplace): demand for skills that
  explicitly reference AI grew 109% year over year, against 23%
  for other in-demand skills. AI integration grew 178%, AI
  chatbot development 71%. Limits: one platform, US-origin,
  growth rates off smaller bases; the most-hired skills are still
  the established ones (full-stack development, virtual
  assistance, data analytics, design). The honest read: applied
  AI work, exactly the freelance and consulting tracks this
  course teaches, is the fastest-growing paid demand on the
  largest freelance marketplace, and it is layered onto existing
  trades rather than replacing them.
- **The same data, the sobering half:** Upwork's Future Workforce
  Index (as reported in the finance guide above) found freelancers
  doing complex AI-assisted work saw earnings rise about 45% year
  over year, while simple generative work saw contract starts rise
  about 90% but per-contract earnings fall about 13%. The money
  concentrates in complex work. That single contrast is the
  course's economic thesis and the reason it is advanced-only:
  the commodity end is already being competed to the floor.
- **Fiverr search demand:** searches for Claude Code specialists
  rose 938% between November 2025 and April 2026 versus the prior
  six months (reported second-hand from Fiverr's data; flagged as
  reported, not independently verified here). Even discounted
  heavily, buyer-side search growth of that order on a second
  marketplace points the same way as Upwork.
- **Money actually moving:** Upwork's Q1 2026 results put
  AI-related work above $300M in annualised gross services volume
  on that platform alone (reported from company financials).
- **Audience size for Claude Code itself:** about 56,000 stars on
  the main community directory; 27,000 learners on one beginner
  course (DataCamp); SemiAnalysis estimated Claude Code authored
  about 4% of all public GitHub commits in February 2026
  (reported via a course roundup). The tool's practitioner base
  is large, growing, and currently underserved past the beginner
  stage on the business side.

## The cost facts the course will teach (checked October 2026)

Every money number in the lessons traces to this table or is
labelled a worked example with stated assumptions. Prices were
checked against Anthropic's own pages by multiple independent
guides in October 2026; the course tells students to re-verify
before quoting a client, because prices move.

- Claude plans: Free has no Claude Code. Pro is $20 a month
  ($17 billed annually) and includes Claude Code. Max 5x is $100
  a month; Max 20x is $200 a month; both are monthly-only, and
  each now returns its price as monthly API credit ($100 and
  $200 respectively, no rollover).
- API list prices per million tokens, input/output: Sonnet 5.5
  $2/$10, Opus 5.5 $4/$20, Haiku 5.5 $0.10/$0.50, Fable 5.1
  $10/$50. The Batch API is half price in both directions.
  Prompt caching cuts repeat context to a small fraction of the
  input rate.
- Headless runs report their own cost: `claude -p` with JSON
  output includes a total_cost_usd field, which Anthropic notes
  is a client-side estimate. That field is the backbone of the
  course's cost-per-job accounting: measure, do not guess.
- Platform fees: Upwork's freelancer service fee is variable,
  0% to 15%, shown before a proposal is sent. Fiverr pays the
  seller 80% of the purchase price. Any honest margin math runs
  after fees, and the course's worked examples do.
- Break-even framing (the honest replacement for income claims):
  a plan pays for itself when hours saved per month times your
  billable rate exceeds the plan price. A $100 Max plan at a $50
  rate needs two saved hours a month. That is arithmetic a
  student can check against their own ledger, not a promise.

## The technical spine, verified current

The course's advanced half teaches the platform as it actually is
in late 2026, confirmed against current docs coverage:

- CLAUDE.md as a layered system (user, project, directory),
  skills (SKILL.md packages), custom subagents, hooks on the
  session lifecycle, MCP servers as connected tools.
- Four ways to run unattended: background agents (Agent View),
  headless print mode (`claude -p` with tool allowlists,
  permission modes, turn and budget caps, JSON output), in-session
  loops, and cloud scheduled tasks (formerly routines) fired by
  schedule, API, or GitHub events; plus the official GitHub
  Action (anthropics/claude-code-action) and the Agent SDK for
  embedding the agent in your own products and pipelines.
- Parallel work: git worktrees per agent, background sessions,
  plan-then-execute discipline on large codebases.
- Cost routes beyond list price: plan versus API break-even,
  prompt caching, batch discounts, model routing (Haiku-class
  for mechanical work, Sonnet-class default, Opus-class for the
  hard core), and free third-party tiers reached through a
  gateway, taught with their terms caveats, since routing Claude
  Code to other providers' free models is off-label use of those
  tiers and the course says so.

## Worth verdict: YES, build it

1. **Demand is real and multi-sourced.** Upwork's earnings-based
   data (AI skills +109%, AI integration +178%), a second
   marketplace's search surge (+938% for Claude Code specialists,
   reported), $300M+ annualised AI volume on one platform, a
   56K-star ecosystem directory, and 27K learners on a single
   beginner course. No single source carries the verdict; the
   sources agree.
2. **The exact angle is unowned.** Advanced tool courses exist
   (free 3-hour official modules; $249 to $795 paid offers) and
   teach operating the tool. Income content exists and is
   unsourced hype. No free, complete, advanced course combines
   the power workflows with the four income tracks (freelance and
   agency delivery, productized services, indie products,
   automation consulting) and real cost math. That combination
   is the course.
3. **It can be taught honestly.** Every input to the money math
   is public and checkable (plan prices, API rates, platform
   fees), the break-even test is arithmetic, demand claims can
   cite platform data with its limits stated, and the failure
   modes are as teachable as the wins: commodity work is being
   priced down in the same datasets that show complex work
   rising. The course makes no income promise anywhere; its
   README will carry a "what this course will not do" section
   saying exactly that.

The sharpest alternative, if this verdict were no, would have
been a pure advanced-workflows course with no income framing.
It is not needed: the income framing is precisely the unowned,
in-demand, honestly teachable part.
