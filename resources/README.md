# Resources

Curated resources for Claude Code for Income, grouped by theme.
Lessons link to the items they use; this page is the full shelf.
Official documentation first, because it ages best. If a link here
breaks, that is a lesson problem: please open an issue so it gets
fixed for everyone.

New to a word? The [glossary](glossary.md) defines every term this
course uses, in plain language.

## Official Claude Code

- [Claude Code documentation](https://code.claude.com/docs): the home of the docs: setup, CLAUDE.md, skills, subagents, hooks, MCP, headless mode, and the CLI reference the workstation modules teach from.
- [Claude pricing](https://claude.com/pricing): the plan and API prices the cost lessons are built on. Checked October 2026 for this course; re-check before you quote anyone, prices move.
- [Claude Code GitHub Action](https://github.com/anthropics/claude-code-action): the official Action used in Lesson 08.
- [Agent SDK documentation](https://platform.claude.com/docs/en/agent-sdk/overview): embedding the agent in your own programs, the subject of Lesson 07's second half.
- [Anthropic Academy](https://anthropic.skilljar.com): Anthropic's own free courses, including Claude Code in Action. The right starting point if this course's prerequisites are not yet met.
- [Anthropic skills repository](https://github.com/anthropics/skills): the official example skills, raw material for Lesson 03.

## The ecosystem shelf

- [awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code): the community directory of skills, hooks, commands, and orchestrators (about 56,000 stars when checked in October 2026). A map for discovery; Lesson 03 teaches how to judge what you find there.
- [awesome-claude-skills](https://github.com/travisvn/awesome-claude-skills): the skills-only companion directory.
- [DeepLearning.AI, Claude Code short course](https://www.deeplearning.ai/short-courses/claude-code-a-highly-agentic-coding-assistant/): a free, MCP-focused 1 hour 50 minute course; a good warm-up for Lesson 06.

## Market data (the sources Lesson 01 teaches from)

- [Upwork In-Demand Skills 2026](https://www.upwork.com/resources/in-demand-jobs-and-skills): the earnings-based demand report behind the course's demand claims, with the growth figures for AI skills, AI integration, and chatbot development.
- [Upwork's freelancer fee schedule](https://support.upwork.com/hc/en-us/articles/211062538-Freelancer-Service-Fees): the variable 0% to 15% service fee the pricing lessons run after.
- [Fiverr's payment terms](https://www.fiverr.com/legal/payments-terms): the 80/20 seller split, in Fiverr's own words.
