# Solution for Lesson 03: Skills as capital: a library that sells twice

The shipped skill at `skills/qa-checklist/SKILL.md` is the worked solution. Its description passes the audit because it does the three jobs from the lesson: it opens with "Use when", it names the moment (before handover), and it carries trigger verbs (check, review, verify, audit, run). Its body is a numbered procedure with a plain pass and fail definition, not an essay about quality.

If your exercise skill failed the audit, the usual cause is the description. A description such as "Helps with onboarding" has no trigger verb with a moment attached and is too short to match a real request. Rewrite it in the shipped pattern: "Use when you need to X: verb the first step, verb the second step, and verb the check that closes the job." Then shorten the body until each step names an action and a check. The library inventory from `skill_audit.py` should list your new skill next to the shipped one, both ok.
