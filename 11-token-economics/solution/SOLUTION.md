# Solution for Lesson 11: Token economics: knowing your cost per job

The fixture already contains the worked answer. retry-storm-booking costs $54.00: 6 million input tokens on Opus class at $4 per million is $24, plus 1.5 million output tokens at $20 per million is $30. The other three jobs together cost $16.40, so the storm is not a rounding error. It is the month.

A fixed version might read: Sonnet class, 2 million input tokens with 1 million cached, 500,000 output tokens, not batched. That prices at $7.20, the same shape as summarize-notes. The saving came less from the class change than from ending the retries: fewer input tokens, a stable cached brief, and a task clear enough to pass review the first time. That ordering, fix the task, then the routing, then the price features, is the lesson in one row.
