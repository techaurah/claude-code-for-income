# Exercise for Lesson 07: Headless mode and the Agent SDK: the agent as a program

Change the job, not just the prompt. Write a job spec JSON for a different unattended job than the demo: a nightly link check on documentation, a changelog draft from merged commits, or a read only audit of a folder. Use a narrower tool list than the demo if the job allows it, and justify each cap in a short note: why that many turns, why that budget, using a labelled worked example with your assumptions stated. Build the command with `headless_driver.py` and review the printed command as if a client were reading it over your shoulder. Then invent a second sample output file with different cost and turn values, run `cost_report.py` on both, and check the two ledger lines differ exactly where your invented inputs differ.
