# Exercise for Lesson 09: Parallel worktrees and background agents

Change the shape of the work. Plan a job with at least four streams where the natural split does create a collision: for example a feature that touches a shared schema file from two sides, or a rename that reaches into many folders. Write the task list with honest file ownership, run `worktree_plan.py`, and read the collision it flags. Then resolve it in the plan, not by deleting the flag: either sequence the colliding tasks with a dependency, split the shared file work into its own foundation task that merges first, or assign the file to one owner and route the other stream through that owner. Run the planner again and keep both outputs, before and after, with one sentence on what the resolution costs in elapsed time.
