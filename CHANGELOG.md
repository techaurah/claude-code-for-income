# Changelog

All notable changes to this course are recorded here. The format
follows Keep a Changelog, and the course versions follow semantic
versioning for the course as a whole.

## [1.0.0] - 2026-11-07

### Added

- Complete course: 32 lessons (00 to 31) across 10 modules, from
  the professional workstation (CLAUDE.md systems, skills,
  subagents, hooks, MCP, headless and scheduled automation) to the
  four income tracks and a capstone client engagement.
- Honest economics foundation: platform demand data with sources
  and limits, plan and API cost tables checked October 2026, and
  the break-even method used throughout the money lessons.
- Lumen Med Spa capstone: simulated client engagement with brief,
  discovery notes, estimator-priced scope, build plan, QA gate
  record, delivery pack, and a self-grading rubric.
- Offline calculators and simulators in every lesson (cost stack,
  scope estimator, price model, pipeline and queue simulators,
  churn math, and more), each with a smoke test run in CI.
- Tools for contributors: a course validator and a relative link
  checker, both wired into CI.
- Visual set in the TechAurah Academy style: course map,
  workstation stack, unattended modes, cost stack, income tracks,
  delivery pipeline, and capstone flow diagrams, generated by a
  committed script.
